# 故事封面图片规格

## 位置
将图片放在此目录：`frontend/public/images/story/`

## 文件名
- **迷雾森林**: `forest.jpg`
- **低语之沙**: `desert.jpg`
- **遗忘之城**: `ruins.jpg`

## 图片规格
- **你的图片尺寸**: 1536px × 1024px (3:2 宽高比) ✅ 完美！
- **推荐尺寸**: 1200px × 800px 或以上 (3:2 宽高比)
- **最小尺寸**: 900px × 600px
- **文件格式**: JPG 或 PNG
- **文件大小**: 建议小于 800KB

## 显示效果
- 卡片中图片高度固定为 **220px**
- 卡片最小宽度：**320px**
- 图片会自动裁切并居中显示（`object-fit: cover`）
- 鼠标悬停时图片会轻微放大（1.05倍）
- 3:2 的宽高比在卡片中显示效果最佳

## 建议内容
- **迷雾森林**: 浓雾笼罩的黑暗森林，古树扭曲，神秘气氛
- **低语之沙**: 金色沙漠，神殿废墟，炙热阳光
- **遗忘之城**: 破败的石柱与拱门，废墟氛围，历史感

## 注意事项
- 如果图片加载失败，会自动隐藏图片容器
- 确保图片具有良好的对比度和可读性
- 建议使用暗色调以配合游戏整体风格
